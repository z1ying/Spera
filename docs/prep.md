## 0. 一句话定位

TPW 代表 120 家社区组织（CBO）在加州监狱里做康复项目，但他们只能证明"我们办了课"，证明不了"我们让多少人没再回去"——因为结果数据（假释、再犯）散在别的系统里。我们做的就是把这两半数据拼起来的框架，并一键生成能拿去国会山争经费的影响报告。

**产品名（建议）**：Spera — TPW Impact Framework。副标题：*From attendance sheets to evidence.*

---

## 1. 问题重述：TPW 到底缺什么

官方题目原文（Luma）：加州惩教部门花在康复上的预算不到 1%；TPW 为 120 家组织发声，但目前只能追踪过程数据（如谁报名了、课上了多久）；需要把假释、再犯等分散记录拼成一个 TPW 和非营利组织普遍能用的影响追踪框架。

拆开看，缺的不是数据，是三样东西：

| 缺口 | 现状 | 后果 |
|---|---|---|
| 关联 | 过程数据在各 CBO 的表格里，结果数据在 CDCR/假释系统里，无共同钥匙 | 有投入，无结果 |
| 口径 | 每家机构各算各的，"完成"的定义都不一样 | 数字不可比、不可加总 |
| 翻译 | 立法者要的是"省了多少钱、少了多少人回去"，不是出勤率 | 游说 BRIGHT/RIGHT 拨款（$2,000–2,500 万量级）时拿不出证据链 |

**钱的逻辑（pitch 的骨）**：TPW 自己的测算——康复每投入 $1，省 $5 监禁成本；每 $1 投入撬动 $26 年度州资金流向 CBO。我们的框架就是给这两个数字装上可审计的证据底座。

## 2. 框架设计：三层

```
[接入层] 各机构脏表 → LLM 字段映射（人工确认）→ 统一 schema
[关联层] 假名化 ID 关联：报名记录 ↔ 释放记录 ↔ 结果事件（不存原始 PII）
[指标层] 口径对齐 CDCR 的指标计算 + 双口径经济翻译 → 一键报告
```

### 2.1 核心实体（统一 schema）

| 实体 | 关键字段 | 说明 |
|---|---|---|
| Organization | org_id, name, program_types[], facilities_served[] | 120 家 CBO |
| Program | program_id, org_id, type（教育/职业/戒瘾/修复性司法/重返支持）, facility, cohort_size | |
| Participant | participant_key（哈希假名）, release_year, age_band, gender, risk_band | **不存姓名/案号原文**；key 由机构本地生成 |
| Enrollment | participant_key, program_id, enroll_date, status, completion_date, credits_earned（MCC/RACC/EMC） | 过程数据主体 |
| Outcome | participant_key, event_type（arrest / conviction / return_to_custody）, event_date, offense_level | 结果数据主体 |
| CostParams | avg_cost_per_year, marginal_cost_per_year, source, year | 经济翻译参数，带来源可换 |

### 2.2 关联与隐私设计（这是评委和 TPW 都会问的，先答好）

- 关联钥匙用**单向哈希假名**：机构在本地用约定盐值把机构内 ID 哈希成 participant_key 再上传，中心库永远不见原始身份。
- 结果数据同理：假释/再犯记录以同一假名 join；框架只输出**聚合统计**，任何小于 10 人的分组自动抑制（small-cell suppression），防止反推个人。
- 一句话 pitch 版："We link records without ever centralizing identities."（只拼记录，不集中身份。）

## 3. 指标字典：口径全部对齐 CDCR

不用自创口径。CDCR 的官方做法：三年随访期，**三年定罪率（3-year conviction rate）为主要再犯指标**，被捕率和再入狱率为补充指标。我们的指标字典直接照此：

| 指标 | 定义 | 用途 |
|---|---|---|
| 三年定罪率（主指标） | 某释放队列在释放后 3 年内被定罪人数 / 队列人数 | 与 CDCR 全州数字直接可比 |
| 一年定罪率 | 同上，1 年窗口 | 早期信号；适合新项目 |
| 完成率 | 完成项目人数 / 报名人数 | 过程→结果的桥 |
| 学分梯度 | 按 MCC/RACC/EMC 学分分层的定罪率 | 剂量-效应证据，最有说服力 |
| 避免再入狱人数 | （基线率 − 项目率）× 项目队列人数 | 经济翻译的分子 |
| 节省金额 | 避免再入狱人数 × 人均再入狱时长 × 成本参数 | **双口径，见 3.1** |

### 3.1 经济翻译的诚实双口径（我们的信誉武器）

LAO（加州立法分析办公室）2025-26 数据：

- **平均成本 $127,788/人/年**——长期、关设施级别的账；
- **边际成本 $21,534/人/年**——短期内少关一个人真正省下的钱（约 3/4 是医疗）。

外行 pitch 只会喊 $127,788，内行评委一问就穿。**我们两个都报**：保守口径（边际成本）写进主报告，平均成本标注为"长期容量口径"放脚注。TPW 对外用的"$1 省 $5"与双口径并不冲突——框架的价值就是让这类数字经得起追问。

## 4. 演示数据：校准过的合成数据（今晚备好）

**为什么合成**：真实个人再犯记录受隐私与法律限制，任何黑客松都不可能拿到——现场明说这一点，是专业而非缺陷。做法是让合成数据在统计上忠实于公开真实数字。

### 4.1 校准锚（全部公开来源）

| 数字 | 值 | 来源 |
|---|---|---|
| 全州三年定罪率（基线） | 39.1%（FY2019-20 队列）/ 41.9%（FY2018-19） | CDCR 再犯报告 |
| 无学分者定罪率 | 45.6% | CDCR 2020-21 报告 |
| 有任意项目学分者 | 39.2% | CDCR 2020-21 报告 |
| EMC（教育学分）获得者 | 26.1% | CDCR 2020-21 报告 |
| RACC（康复学分）获得者 | 21.1% | CDCR 2020-21 报告 |
| CBO 项目参与者再入狱率 | 21%（vs 全州 44%） | TPW 官网 |
| TPW 触达人数 | 19,043 | TPW 官网 |
| 人均监禁成本（平均/边际） | $127,788 / $21,534 每人每年 | LAO 2025-26 |

注意 CDCR 的梯度本身就是现成的剂量-效应故事：45.6% → 39.2% → 26.1% → 21.1%，参与越深、定罪率越低。合成数据的任务就是复现这条梯度。

### 4.2 生成规格

- 规模：5,000 名参与者 × 8 家虚构 CBO × 3 个释放队列（2021/2022/2023，保证三年随访已完成）
- 分布：报名→完成→学分→结果用条件概率链生成，参数调到边际分布命中 4.1 的锚（±2 个百分点内）
- 脏度：故意注入真实世界毛病——日期格式不一、机构各用自己的项目命名、缺失值、重复行——因为周末的演示重点就是"脏表进、干净证据出"
- 验收（今晚跑）：生成后自动校验报告——各分层定罪率 vs 锚点对照表，全绿才算备好

## 5. 脏表导入：120 家机构怎么喂进来

真实世界里 120 家 CBO 的表格不可能同构。导入流程：

1. 上传 CSV/Excel → 系统抽样前 20 行
2. **LLM 提出字段映射建议**（"StartDate" → enroll_date，置信度标注），低置信字段标红
3. 人工确认/修正映射（一次性，存为该机构的映射模板，下次自动套用）
4. 校验关：类型、日期范围、重复 participant_key、完成日期早于报名日期等异常逐条报告，不静默吞掉

演示准备：今晚预制 3 份风格迥异的样例表（英文列名/缩写列名/西班牙语列名各一份），现场轮流导入。

## 6. 产出物：一页资方级影响报告

固定结构，一键生成（PDF/网页）：

1. **头条数字**：本队列三年定罪率 X% vs 全州基线 39.1%；避免再入狱约 N 人
2. **队列图**：报名→完成→学分→结果漏斗 + 学分梯度条
3. **钱**：保守口径节省 $A（边际成本）；长期容量口径 $B（平均成本）——双口径并列，方法脚注写清
4. **口径说明**：指标定义对齐 CDCR 三年定罪率；数据质量等级（A=结果已关联 / B=仅过程数据）逐机构标注
5. **免责**：演示数据为按公开统计校准的合成数据（现场版）；真实部署时替换为机构真实记录
