# TPW Network dashboard：可视化优化与业务 insight 建议

2026-10-24 · 基于当前真实数据（TPW 提供的 36 条项目记录 + Spera 提交）

## 一、可视化与观看友好

1. **当年数据要标明“未完成”**
   - 2026 年的点会掉得很低，因为大部分班还在进行，完成人数还没出来。现在用 `2026*` 加脚注说明。
   - 更好的做法：当年那段线画成虚线，或者改成“截至同月”的同期对比（今年 1–10 月 vs 去年 1–10 月）。

2. **完成率单独画，不用双 Y 轴**
   - 人数和百分比放在同一张图里容易误读。
   - 建议在趋势图下方加一条小的“完成率”折线，共用年份轴。

3. **TPW 的头号指标放在第一位**
   - TPW 自己报表里最核心的是 Total Participant Programming Hours，它最能体现“做了多少”。
   - 建议把它放在 KPI 第一格，并在卡片里加一条小趋势线（sparkline）。

4. **KPI 加同比**
   - 例如“706 人，比去年 +2%”。只有数字没有对比，看不出好坏。

5. **口径统一，悬停可看定义**
   - KPI 的完成率只算“已结束的班”，漏斗的百分比是“完成 ÷ 全部参加”，两个数会不一样。
   - 建议漏斗也只算已结束的班，或者两处都加 ⓘ 悬停说明。

6. **监狱覆盖地图**
   - 用 31 个 CDCR 监狱做方块格（tile grid）。有项目的上色，深浅代表参与小时；RIGHT 4.0 underserved 的监狱加描边。
   - “哪里有、哪里没有”一眼就能看出来。

7. **估算和精确数据分开显示**
   - 过往补填的数据（source = estimate）在图上用浅色或斜纹，表格里已有 “Estimate” 标签。
   - 用于对外数字时，可以切换“只看精确记录”。

8. **数据完整度提示条**
   - 例如：“本视图 37 条记录中 3 条缺字段 · 最近一次提交：10 月 22 日”。
   - 让管理层知道数字有多可信，数据多新。

9. **Generate report 改成固定一页的打印版**
   - 现在打印的是整个页面。建议做专门的打印样式：一页 A4，包含 KPI、趋势、覆盖、节省估算，以及当前筛选条件和日期。

10. **只选一年时怎么呈现（目前的实现）**
    - 显示“参加 → 完成”漏斗。
    - 可以再加：当年按季度或月份的开班数（看季节性），或者按项目、监狱对比完成率的横条图。
    - 一年没有“趋势”，适合看“结构”。

## 二、契合 TPW 需求的业务 insight

TPW 的工作是：替成员机构争取经费（RIGHT/BRIGHT）、向 CDCR 和议员证明项目有效、协调 120+ 机构。下面按对这三件事的价值排序。

1. **RIGHT 4.0 申请准备度（截止日 2026-11-30，最紧迫）**
   - 按机构列出：是否满足“前 5 年里至少 2 年在 CDCR 监狱提供项目”，已有哪些加分证据（underserved 监狱、RHU/EOP/MHCB、非英语授课），还缺什么。
   - TPW 可以据此在截止前主动辅导最接近达标的机构。
   - 数据都已在库里（`priorService`、`right4Signals`），只需要做成一张“准备度”表。

2. **数据覆盖率本身就是关键 insight**
   - 目前只有 2 家机构有数据，而 TPW 有 120+ 成员。
   - 建议显示“已报送机构 / 成员总数”，再按监狱看覆盖。这是 TPW 推动机构报送的抓手，pitch 里也能讲“从 2 家到 N 家”。

3. **服务缺口：哪些监狱没有项目**
   - 尤其是 RIGHT 4.0 列出的 underserved 监狱（ASP、CCWF、CIW、CTF、KVSP、NKSP、SAC）。
   - 这是 TPW 向 CDCR 争取准入、引导机构去缺口监狱的直接依据。

4. **项目强度（dose）**
   - 每位完成者平均参与小时 = participant hours ÷ completed，按项目比较。
   - 给立法者讲“深度参与”比讲人数有力，也正好对应 CDCR 学分越多、再犯越低的梯度。

5. **完成率异常提醒（用于关心，不用于评判）**
   - 某个项目或监狱的完成率明显低于网络中位数，而且样本够大（例如 ≥ 20 人）时，标出来。
   - 常见原因是监狱封锁、转监、排课冲突，正是 TPW 可以向 CDCR 反映的“制度性问题”，这也是 one-pager 里写的 TPW 职能。

6. **节省估算对外口径**
   - 目前用的是 CDCR“有学分 39.2% vs 无学分 45.6%”，是最保守的一档，并且注明了“相关不等于因果”。
   - 对外只用保守口径（边际成本），容量口径作为补充。
   - 如果能拿到各机构的项目预算，就可以算“每投入 $1 节省 $X”，直接对应 TPW 官网的 $1 → $5。

7. **公平性视角**
   - 女子监狱、RHU/EOP/MHCB 和非英语项目各占多少参与者，对比这些人群在 CDCR 总人口中的比例。
   - 这类内容在拨款和立法沟通中很受重视。

8. **报送及时性和提醒**
   - 现在的“报送及时性”只统计在 Spera 上提交的记录，导入的表格和补填数据没有提交时间。
   - 下一步：项目结束 14 天后自动提醒未报送的机构，并把“平均几天报送”做成趋势，看提醒有没有效果。

9. **按选区汇总（需要额外数据）**
   - 把监狱映射到州众议员和参议员选区，生成“你选区内的监狱有 N 个项目、M 人完成”。
   - TPW 去 Sacramento 游说时可以直接带给议员。

## 三、这次没有照搬效果图的部分

- **Release cohorts（出狱队列）**：效果图里的数字是合成演示数据，我们没有出狱人数的真实来源，所以没有做。将来如果能拿到 CDCR 的公开出狱统计，可以再加。
- **Program type**：数据库里没有“项目类型”字段，筛选器先用“Program（项目名）”。如果 TPW 有分类（如教育、职业、康复、艺术），加一列就能换成类型。
- **Current records / Retroactive 按钮**：按你的要求没有加。补填的估算数据在表格里有 “Estimate” 标签。
