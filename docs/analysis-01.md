# TPW 数据分析简报 #01（2026-10-23 晚）

**数据**：`hsi-demo-data/` 校准合成数据（5,000 参与者 + 2,000 对照，seed=42，验收全绿）。以下"数据发现"均为该数据集内结果；"真实世界参照"另行标注来源（design doc §18）。合成数据按 CDCR 公开统计校准到学分层，因此**学分/完成相关的结论与官方发现同向**；未校准的维度（如按年龄、风险带）不产生可引用结论，见 §4。

---

## 1. 桃子的四个问题，逐个回答

### Q1：哪种课程最能让人靠技能挣钱、不再犯？

**数据发现**：按项目类型看三年定罪率几乎无差异——教育 37.7%、重返支持 37.7%、戒瘾 37.9%、修复性司法 39.5%、职业培训 40.2%。但**完成与否差异巨大：完成者 35.0% vs 辍学者 47.3%（差 12.3 个百分点）**；辍学者基本等于没上过课（无学分基线 45.6%）。

**解读**：在这套按官方统计校准的数据里，起作用的不是"选了什么课"，是"**上完了没有、拿到学分没有**"。这与 CDCR 的 Prop 57 官方发现同向：学分梯度 45.6% → 39.2% → 26.1% → 21.1% 是按参与深度分层的，不是按课程名分的。

**对"技能→挣钱→不犯罪"假设的诚实裁决**：方向上合理，但现有公开证据支持的是"完成+学分"这个更上游的杠杆；没有公开数据支持"职业培训单独优于其他类型"。产品与 pitch 里**不要编造职业培训的优越性**——我们的引用纪律不允许。可讲的版本是："钱应该花在让人上完课上——出勤支持、完成激励、学分衔接——因为辍学等于白上。"

### Q2：再犯集中在刚出狱还是两三年后？

**数据发现**：首次定罪距释放的时间分布——第 1 年内约 33%、第 2 年约 36%、第 3 年约 26%（按年粒度）；以完成者计，**48.6% 的再犯发生在完成课程后 12 个月内**。风险前高后低，但不是只集中在头几周：第一年是峰值窗口，第二年仍然很高，第三年才明显回落。

**产品含义**：① 随访与支持的密度应该按"第一年最密"设计；② TPW 的影响评估用三年窗口是对的（CDCR 口径），但干预的价值时点在第一年——报告里值得单列"一年定罪率"作为早期信号指标（design doc §3 已预留）。

### Q3：再犯的罪名轻重构成？重罪的人是不是更难改？

**数据发现**：首次再定罪中重罪（felony）50.5%、轻罪（misdemeanor）49.5%，约对半。**真实世界参照**：CDCR 社区重返项目（MCRP/FCRP）参与者的再定罪约 55–60% 为重罪；重审减刑队列的再定罪则以轻罪为主（California Policy Lab）。即构成随人群而变，对半开是合理量级。

**诚实裁决**：本数据集**没有按"原始罪名轻重"校准**，"重罪者成功率更低"这个假设今晚无法用我们的数据检验（生成器没有这个维度）。真实世界里它需要按原始罪名分层的队列研究才能答——列入给 TPW 的问题清单（他们若有 CDCR 分层报告即可验证）。pitch 中不引用未检验的假设。

### Q4：机构之间有差异吗？

**数据发现**：8 家机构定罪率 35.2%–40.2%，跨度约 5 个百分点；小机构（n=230）波动含抽样噪声。**含义**：机构对比可以做，但必须带样本量标注与小单元抑制，禁止裸排名——这正是框架"数据质量等级"存在的理由。

## 2. 可以进仪表盘的图（每张都有数据支撑）

## 3. 不许进展示的切法（防止假洞察）

- 按年龄段、风险带的定罪率：本数据未校准这些维度，切出来是噪声（风险带甚至呈反直觉假象），展示即造假
- 按项目类型的"效果排名"：差异在噪声范围内，只能展示完成率差异，不能说某类课"更有效"
- 机构裸排名：必须带 n 与抑制规则
